🚀 Telegram Social Media Downloader Bot

A multi-platform Telegram bot that makes downloading social media videos and media easy. It supports 21 popular platforms through third-party downloading services.

✨ Features
🌐 Supports 21 social media platforms.
📥 Easy media downloading through Telegram.
⚡ Integrates third-party downloading services.
🎵 Video and audio downloading where supported.
🔗 Simple link-based downloading.
🤖 User-friendly Telegram interface.

🔌 Third-Party API

This project integrates an externally available media downloading API.

API Endpoint:

text
https://tele-social.vercel.app/down


Important: This API is not owned, developed, or maintained by this project. It is a third-party service discovered online and used for media downloading functionality.

API availability, supported features, response formats, and limitations are controlled by the respective API provider.

⚙️ Technologies & Services
Cobalt – Media downloading service.
APIOR – Third-party API integration.
yt-dlp – Media extraction tool.
Telegram Bot API – Telegram bot functionality.
