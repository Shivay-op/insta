## About

A simple and convenient Telegram bot for downloading social media videos and media.

Send a link. Let the bot process it. Get your media directly in Telegram.

**One bot. Multiple platforms. One simple experience.**

## Features

- **21 Platforms** — Support for popular social media websites.
- **Simple Experience** — Send a link to start downloading.
- **Video Support** — Download supported videos and reels.
- **Audio Support** — Audio extraction where available.
- **Multiple Services** — Uses Cobalt, APIOR and yt-dlp integrations.
- **Telegram Based** — Everything accessible through Telegram.

## API

This project integrates an externally discovered third-party downloading API.

<div align="center">

### Tele Social API

[![API](https://img.shields.io/badge/OPEN%20API-6366F1?style=for-the-badge&logo=vercel&logoColor=white)](https://tele-social.vercel.app/down)

`https://tele-social.vercel.app/down`

</div>

### Example

```http
GET /down?url=VIDEO_URL
```

```bash
curl "https://tele-social.vercel.app/down?url=VIDEO_URL"
```

> **Note:** The API is a third-party service. It is not owned, created, or maintained by this project. Its availability and functionality are controlled by its provider.
